# Поклонная гора — фронтенд (React + Vite)

Адаптивная (mobile-first, с десктопной bento-сеткой) вёрстка сайта церкви по макету:
Главная, Расписание, Сборник песен, Новости и блог, О церкви, Поддержать,
детальные страницы события, гимна и проповеди.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm run build      # сборка в dist/
```

## Данные

Расписание (главная, список событий, событие, проповедь), сборник песен (список, поиск, песня с аккордами),
страница «Новости и блог», контакты церкви, дежурства служителей и страница пожертвований (суммы, цели,
реквизиты с QR-кодами) загружаются из API бэкенда — см. `src/api/` и [../backend/README.md](../backend/README.md).
Истории-комиксы (`src/data/stories.js`) и плашка «В эфире» пока заданы во фронтенде.

Кнопки «В календарь» (страница события) и «Подписаться» (расписание) берут ссылки из API —
см. раздел «Календари» в [../backend/README.md](../backend/README.md).

Контакты и дежурства нужны на каждой странице, поэтому загружаются один раз (`src/api/ChurchProvider.jsx`)
и запоминаются в `localStorage`: при следующем заходе они показываются сразу, а затем обновляются ответом API.

Запросы идут на `/api/v1` того же домена. В разработке Vite проксирует `/api` на бэкенд
`http://localhost:8300`; другой адрес задаётся переменной окружения `API_PROXY_TARGET`.
Если API живёт на отдельном домене, укажите его при сборке в `VITE_API_URL`.
