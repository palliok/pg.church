# Handoff: Редизайн сайта и приложения церкви — общий обзор

## О файлах
`Design Overview.dc.html` — главный референс. Откройте его в браузере (рядом должен лежать `support.js`). Это **дизайн-макет на HTML** с инлайн-стилями, а не продакшн-код: переносите визуал и поведение в стек проекта (React/Vue/нативно и т.д.) по его паттернам, разметку один в один не копируйте.

В каждом блоке обзора две колонки:
- **БЫЛО** — старая версия (подтягивается из `Site v2.dc.html` и `App v2.dc.html`, нужны только для сравнения).
- **СТАЛО** — новая версия, её и нужно реализовать.

`Event Page v3.dc.html` — интерактивная версия страницы события (вариант **1A**) на трёх типах событий, с рабочим раскрытием описания. В обзор (блоки 08/09) перенесена её статичная копия для богослужения.

## Fidelity
**High-fidelity.** Цвета, шрифты, размеры, отступы и hover-состояния финальные. Фото и карты — заглушки (полосатые плашки с моноширинной подписью), в них подставляются реальные изображения / Яндекс.Карта.

## Шрифты (Google Fonts)
- **Arimo** 400/700 — заголовки, названия, текст. Заголовки с плотным трекингом: от −0.035em (17px) до −0.065em (88–120px), line-height 0.85–0.9.
- **Prata** 400 — числа дат, время, номера.
- **JetBrains Mono** 400 — подписи КАПСОМ, теги, метки, текстовые ссылки («ВСЁ РАСПИСАНИЕ →»), letter-spacing .02–.06em.
- **Material Symbols Rounded** — иконки (`location_on`, `call`, `ios_share`), FILL 1.

## Радиусы и тени
- Крупные карточки: 26–32px; средние: 20–24px; плашки дат: 14–20px; кнопки и теги — pill (99px).
- Контуры делаются `box-shadow: inset 0 0 0 1px …`, а не border.
- Тени почти не используются; исключение — плашка адреса над картой: `0 10px 30px rgba(35,31,32,.08)`.

## Общие паттерны
- **Тег**: высота 28–34px, padding 0 11–14px, pill, JetBrains Mono 11–13px, контур pill-stroke.
- **Эфир**: красная pill, белая точка 6px + «ЭФИР».
- **Кнопка «Подробнее»**: белая pill, текст Mono + чёрный круг 40–44px со стрелкой ↗.
- **Основная кнопка**: cyan, высота 52–60px, Arimo 500 17–19px.
- **Строка события в списке**: grid `56px | 1fr | auto` — плашка даты (число Prata + месяц Mono), название Arimo 700, время Prata, стрелка. Hover — фон cyan, radius 22px, transition background .2s.

## Страница события (08/09, вариант 1A)
**Десктоп 1440**, padding 28/32/56. Сверху ссылка «← РАСПИСАНИЕ». Дальше grid `minmax(0,1fr) 460px`, gap 64:
- **Левая колонка** (gap 44): теги (ЭФИР / тип / «КАЖДЫЙ ЧЕТВЕРГ» на cyan для регулярных) → заголовок Arimo 700 112px → «О СОБЫТИИ»: лид 24px (2–3 строки) + кнопка «ЧИТАТЬ ПОЛНОСТЬЮ ↓», которая раскрывает остальной текст (18px, #4A4647) и меняется на «СВЕРНУТЬ ↑» → «ПРОПОВЕДЬ» (тёмная карточка: автор, место Писания, название Prata 40px, кнопка «КОНСПЕКТ →») → «ГИМНЫ СЛУЖЕНИЯ»: список строк с разделителями (ГИМН + номер Prata 28 | название 24px | стрелка), hover cyan.
- **Правая колонка** (gap 36): **инфо-панель** (radius 30, padding 42/30/24) — число Prata 160px + месяц Mono 30px + день недели; время Prata 46px; линия; место + адрес + круглая кнопка ↗ «Как добраться»; ряд кнопок: основная (cyan) + вторичная (белая) + круглая «Поделиться» 58px (`ios_share`). Под панелью — «РЯДОМ ПО ДАТАМ» (3 строки, в плашке дата + **месяц**).
- Цвет инфо-панели зависит от типа события: богослужение #E2E3DA, разовое событие (фестиваль) #02B7E3 (основная кнопка тогда ink), регулярная встреча #231F20 (текст белый).
- Кнопки по типу: богослужение «Смотреть» + «В календарь»; фестиваль «В календарь» + «Как добраться»; Молодёжка «Написать в чат» + «В календарь».
- Проповедь и гимны показываются только у богослужения.

**Мобилка 390**: «← РАСПИСАНИЕ» → карточка-«билет» цвета типа события (теги, заголовок 46px, дата Prata 80 + месяц 20px + день недели, время, место с кнопкой ↗, кнопки: основная во всю ширину; вторичная + круглая «Поделиться» 46px в ряд) — без разделительных линий внутри → описание с раскрытием → проповедь → гимны (список с линиями) → «Рядом по датам».

## Состояния и поведение
- Hover строк списков/карточек: фон #02B7E3, transition .2s.
- Раскрытие описания события: локальный boolean на страницу.
- Метка «СЕГОДНЯ» / «ЧЕРЕЗ 3 Ч» вычисляется от текущей даты; «ЭФИР» — если у события есть трансляция и она идёт.
- Мобильные карусели: горизонтальный скролл, `scroll-snap-type: x mandatory`, без скроллбара.

## Данные события
`title, type (service|oneoff|regular), regularLabel?, date, timeStart, timeEnd, place, address, metro, lead, body, live?, streamUrl?, sermon? {author, role, ref, title}, hymns? [{number, title}], nearby[]`.

Изображений нет: фото и карты — заглушки. Иконки — Material Symbols Rounded. Логотип набран шрифтом (Arimo 700 «церковь.» с точкой #02B7E3 + «на поклонной горе» + «САНКТ-ПЕТЕРБУРГ» Mono), см. блок 01.
